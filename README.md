Entry for [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8) on make.fun.

`main.py` writes exactly one word to `entry.txt`: the sound of wind moving through trees. It is a rare word, it paints a clear scene in a few letters, and it sounds like what it means.

Run it with `python3 main.py`. It writes to `$OUTPUT_DIR/entry.txt` when that is set, otherwise to `/output/entry.txt`.
